# 通用步骤与必换参数

| 部分 | 可通用 | 下次处理 |
| --- | --- | --- |
| 权威依据 | 最新指令优先，明确源文件 | 【替换】实施方案、进度表、模板版本 |
| 教学单位 | 一完整项目一份设计 | 【替换】课程、项目总数；当前7项目 |
| 项目边界 | 输入—任务—交付—评价 | 【替换】编号、名称、目标、前后项目接口 |
| 时间 | 默认课上:课下1:2，总体＝活动＝任务＝交互分段 | 【替换】课时分钟换算、课内总量、课下预计工作量、授课次数 |
| 活动任务 | 按工作过程与难点拆分 | 【替换】数量、内容、顺序；不固定6活动12任务 |
| 知识图 | 四类型、九类语义、线上标签、无填充、红蓝绿 | 【替换】节点、关系、先决知识、中心与分支数 |
| 目标 | 知识点（水平），总目标按活动一一对应的具体知识目标与成果证据 | 【替换】具体知识、水平、能力素质表现 |
| 模板 | 直接填充、保留合并、渲染检查 | 【替换】学校/课程/学年学期/周次、模板行块profile |
| 交互 | 策略方法行为时间一致 | 【替换】学情、组数、演示练习、汇报覆盖机制 |
| 资源 | 分类、实际名称和使用位置 | 【替换】数据、字段、工具、课件、表单及章节 |
| 评价 | 与成果对应、沿用获批标准 | 【替换】本项目条款；不默改总评及权重 |
| 反思 | 项目末尾只写一次 | 【替换】真实问题、指导、证据、改进；无记录标建议稿 |
| 输出 | Word/PDF同步、Visio原生可编辑 | 【替换】文件名、页数、图数、保存位置 |

参数卡：课程；项目编号/名称；源文件和版本；授课对象；学年学期/周次；学时换算；课上分钟；课下预计分钟；授课次数；项目输入；交付成果；活动任务数量（设计后填）；资源清单；评价来源；真实课堂记录；本次授权范围。

项目一示例：通信运营业务需求分析与数据认知，4学时=180分钟课上，2×90分钟；课下预计360分钟；6活动12任务；19图=1总图+6活动图+12任务组块。用户曾说“假如8学时”是举例，不是项目一实际学时。

当前覆盖旧规则：不再使用“活动目标展开全部新知识”或180/90；目标6项对应6活动，任务组块仅图；用户最新删除与勾选格式优先。

更新：不按蓝色框架名称直接选目标；按实际成果选择具体知识点及学习水平。思政逐项同名入图；交互按编号行动环节+时间+提问+预期。项目一新目标见goals-ideology-interaction.md，旧六方法框架目标已废止。
