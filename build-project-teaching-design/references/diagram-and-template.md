# 绘图与模板实施

## 数据先行

用稳定ID保存知识名称、类型、颜色、水平；用source/target/relation保存关系；活动任务引用知识与资源ID。所有格式由同一份数据生成，避免名称分叉。结构见 `../assets/project1-example.json`。

按输入、任务、成果、评价拆分活动，不固定项目一数量。先核总量后写交互；课下预计工作量不得计入规定课内学时。

## 核心居中

1. 核心中心放(W/2,H/2)，分支按真实语义环绕，不固定六分支。
2. 细节放相应分支外圈，先决知识与范例邻近所支撑组块；对称不能改变语义。
3. 测量文字后定框，合理换行，不能用极小字体硬塞；先消除节点重叠再布线。
4. 线到边界，箭头可读；标签靠所属线段，避节点、其他标签和交叉点。减少交叉，但不能为布局歪曲关系。
5. 切出活动图及任务组块，名称类型一致；每活动不得复用整张总图，每任务不得都用活动图。
6. 原尺寸与插入Word后均检查清晰度；总览与细图配合阅读。

## 原生Visio

VSDX使用可编辑形状、文字和线，不能放PNG后称节点可编辑。核对页面名称、形状类型、文字和连接关系。检查ZIP/XML结构，并用原生Visio或可用兼容工具实际打开/导入，核对页数与非空内容。LibreOffice导入不等于Windows Visio完全验证，须准确说明。

同数据可生成矢量PDF和PNG预览；精确知识图不用AI图像生成。修改后同步所有格式，不能只有PNG已更新。

## 填充原DOCX

先读document.xml中的grid、gridSpan、vMerge；以原文档为起点，克隆原活动表与任务行块。避免合并格重复赋值覆盖内容。

当前内置确认版模板：第0表前9行总体区，行9—10课上课下一活动对；第1表前4行活动区，行4—11一任务块（用户编辑版已删除逐任务备注），知识组块跨3行。行数公式：总体9+2×活动数；活动4+8×任务数，末活动另加一次备注行。此公式仅适用本模板，换版必须重分析。

行高用至少值而非固定值，适当用cantSplit、keep_with_next；不把长表全部锁为不分页，也不为消除所有跨页而改模板。图片按单元格可用内宽减边距计算。本次经验：总图/活动图13.7cm、任务图6.8cm，不是通用固定尺寸。

## 反思与同步

保留备注字段，前面空或“／”，仅最后一个任务备注填项目整体反思；用户明确允许时可末尾另设反思区。不能每活动保留“实施后记录……”占位语。

渲染最新DOCX并逐页查文字截断、图片越界、表头断开、异常空白，再更新PDF及下载包。页数是结果，不是要求。源文件变化后仅重做受影响输出；检查通过无需无理由重复渲染。

优先保留最新编辑稿中的删改。每个活动目标仅一项最高阶知识点；任务格只有图。全量教学方法勾选保留，不改成仅列已用方法。框架到内部知识统一核对内容包含方向，思政节点与素质目标用相同名称。概览资源用分类短名，任务资源再具体到名称和使用处，避免窄列塞大段全文导致跨页。

活动与任务内部拆分线使用节点间的分支走廊，避免斜线穿过其他节点。插入Word后单独检查任务图字号，必要时提高原图字号、收紧裁剪并重排节点，不仅增大整张画布。资源行与成果评价行尽量成组，避免末页只留一行；可调整段落间距及非固定行高，但不改变列宽与合并。总体日期范围须覆盖全部实际授课次数。

Visio文本使用其原生字体度量单独校准，不能照搬PDF字号；重点检查两行节点是否溢出、标题与图例是否重叠、圆柱帽线是否穿字。VSDX页面XML写回保持Visio默认命名空间并实际导入，不能仅检查ZIP正常。关系标签给箭头留空间，不能用白底盖住方向。

目标栏不能从蓝色方法框架机械复制；读取goals-ideology-interaction.md核对实际成果。将素质目标拆为具体同名思政节点，逐项同步到总图与活动图。活动图新增辅助连线时检查整个节点外框，不只比较中心点；必要时从底部空白通道绕行，避开宽圆柱。
