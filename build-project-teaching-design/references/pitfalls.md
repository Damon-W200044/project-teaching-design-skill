# 踩坑与解决办法

| 坑 | 原因 | 有效处理与检查 |
| --- | --- | --- |
| 仍做32课次 | 沿用历史粒度 | 锁定7项目结构，一个项目容纳多次授课 |
| 核心偏左、总图树形 | 仅按层级排布 | 固定中心(W/2,H/2)，知识组块环绕，检查插入后的视觉中心 |
| 讨论汇报成知识点 | 混淆内容与行为 | 提炼规则、方法、概念，讨论留在策略与交互 |
| 有线无线名 | 当成思维导图 | 逐线标合法语义，读成可解释句子 |
| 全部包含或支持 | 为布局牺牲语义 | 区分总分/分总、前提/辅助、上下位/并列，不凑齐九类 |
| 漏知识与先决技能 | 抄教材标题 | 从成果倒推口径、字段、检验规则及必要已有技能 |
| 模板栏目相同但版式错 | 重新建近似表 | 直接填原DOCX，克隆原表/行块，比较gridSpan与vMerge |
| 图片右边裁切 | 按纸宽估计 | 按单元格内宽；本次13.7/6.8cm有效，换模板重算 |
| 总目标过细或泛泛 | 未区分最高阶与明细 | 总体写最高阶知识点（水平），活动展开 |
| 总时长不闭合 | 写完再补时间、导入重复计 | 单数据源核总量/活动/任务/交互，导入计入明确分段 |
| 短任务堆全班汇报 | 内容时间失配 | 按目标选策略，长任务分段，按组数设计并行反馈 |
| 地点填机房 | 沿用传统习惯 | 只填课上/课下，设备放资源 |
| 资源只有代码或泛称 | 内部ID直接交付 | 展开类别、文件名、章节/字段；不虚构附件 |
| 每任务备注补步骤 | 误解备注 | 前面空/“／”，项目末尾仅一次反思 |
| 反思编课堂事实 | 缺记录仍写完成率 | 标建议稿，不编人数、效果、比例 |
| VSDX打不开或只有图 | 封装错或截图冒源 | 原生节点文字线，检查包结构并实际打开/导入 |
| Word新而PDF/包旧 | 输出分开维护 | 最后渲染后同步全部输出，核版本与时间 |
| 重跑脚本覆盖修订 | 硬编码路径、重建旧模板 | 不直接重跑build_project1.py；先拆数据/模板/配置，在新目录复现 |
| 新会话路径失效 | 临时路径当持久身份 | 交接保留文件名、持久ID及版本，解析文件后再设路径 |
| 把已交付当已验收 | 状态混淆 | 分清生成并检查、用户反馈、待最终审阅 |

自动核对不替代专业判断：语义成立、学情匹配、知识图易读和实际学习效果须人工确认，不能为通过检查修改规则掩盖问题。

## 本轮批注新增（覆盖旧口径）

| 问题 | 处理 |
| --- | --- |
| 重新加回已删除项目/活动/任务主题 | 以用户编辑稿为版式基准，仅保留必要序号和字段 |
| 课上180/课下90不符合通常比例 | 调整为180/360；课下补实质工作、互动及核验，不只乘数字 |
| 6活动总体写7目标、活动目标仍列细目 | 总体严格6项，一活动一最高阶知识点；活动表也只该一项 |
| 任务图后重复列知识点 | 删除重复文字，仅保留对应图 |
| 只保留已选教学方法 | 全部选项保留，所用项前勾选，其他栏写实际方式 |
| 勾了讨论但无讨论结果汇报 | 交互写问题—讨论协商—学生汇报—反馈，计算并行汇报时长 |
| 所有内部知识反向“支持”框架 | 框架到细目改内容包含；思政/先决/真正辅助范例才考虑支持 |
| 素质栏有思政而总图没有 | 增加同名思政节点及关系，并在任务落实 |
| 批注无range锚点被漏读 | 检查commentReference所在段落，不能因提取器anchors为空而忽略 |
| 用户只保留第一活动表 | 把它作为确认版式，续全6活动，不把样式编辑误当删去其余教学内容 |

新增复核：任务图原图可读不代表插入后可读，须按实际6.8cm等尺寸检查；斜线不能穿其他节点；资源名称在JSON与Word保持同一份配套材料；日期不能只标第1次却覆盖2次授课；避免成果评价单行尾页。

图形复核还应检查：圆柱顶部椭圆不要穿过多行文字，可使用浅帽并校准文字位置；关系标签不能铺满整段连线而遮箭头；Visio与PDF字号度量不同，应分别验证；页面XML意外改成ns0前缀可能导致兼容工具导入空白，保持Visio默认命名空间并重开检查。

本轮再次纠正：6个目标数量正确不代表知识点选择正确；不能直接抄蓝色框架名。思政栏有文字、图中有总标签也不代表逐条落实，须按具体要求一一映射。交互有分钟数也不代表写法合格，须按参考图给编号行动环节、关键问题和预期回答。修改后把Word总图与单独图文件一起核对，防止用户实际看到的仍是旧图。

本轮复核补充：活动图中的思政支持边不能只在局部存在、总图缺失，需逐边对照；压缩交互后仍须保留图与评价要求的交付流程教学；新增思政连线应走节点外的通道，避免穿过宽圆柱或先决知识节点。
